# Support-Lifecycle kill test：当前候选退出核心

日期：2026-10-03。执行：六路冷启动子代理，root 补审 view maintenance 并交叉
复核结果。七条理论线与公开原生载体均有定向审查；不是全球文献穷尽证明。

**结论：当前提出的 operation-specific support lifecycle 不升格为独有核心。**
替代支持、局部失效、按结果付费取证、带撤销/消费的授权证书与动作前全称保证
都有直接成熟近邻；本轮未找到同保证下不可消去的经典成本或适用范围缺口。
因此不进入以该抽象为新算法的原生候选构造，也不为它安排优势实验。

这只关闭当前主张。能在通用框架内表达，不证明所有具体结构算法都没有增量；
尚未核实完整同目标实现，也不授予当前候选新颖性。已取得的 BRFP、R4 与
原生构造结果保留其原范围；不把整合/适配改称理论首创。

## 1. 七条线的 kill 结果

| 理论线 | 不能独占的直接覆盖 | 必须保留的界限 |
| --- | --- | --- |
| Epistemic / contingent planning | 全 belief 的动作前提、带前提和费用的 sensing、按结果分支；有限记忆 strong policy 可编码生命周期与任务进展 | reduction 和规格级 reference 不等于已实现高效原生编译；perfect recall 不能免费提供丢弃的信息 |
| Active information acquisition | SBFE 的 0/1-certificate 对所有相容补全确定目标；DNF/CDNF 替代证据，自适应付费查询 | 结果未知时不能用 oracle 最便宜 witness 当合法查询策略；近似界的独立性等前提不可省略 |
| Truth maintenance / ATMS | 多个最小 environments、label delta 传播、defeasible retraction、切换 surviving support | 最小包含关系不等于最小成本；规则完备性、native evidence 合法性仍需共同验证 |
| Provenance / semirings | 加法替代、乘法联合、多推导增量删除与 trusted grounding、最小 witness 文献 | database repair 改世界，query 改知识；共享证据一次计费不能直接套 leaf-occurrence tropical 成本 |
| Materialized view maintenance | 受影响/可自主维护条件、alternative derivation counting、DRed、共享中间结果、物化/增量/重算选择 | 无观察的外写不是免费 update delta；非关系型 API 的精确 contract 不自动可得 |
| Authorization / capability systems | LPCFS 把依赖证明、time/state 条件、撤销与一次性消费接到真实文件访问；abductive credential gathering | 准许访问不保证 I/O 成功；重新读凭证不能恢复已消耗权限；exact effect 须另有精化/故障契约 |
| Runtime verification / synthesis | belief/knowledge monitors、partial-observation permissive shields、dynamic/selective observation | pre-action gate、进展和原子性不可省略；有界有限可解不等于高效最小总成本 |

以上既含直接现成算法，也含本次给出的条件 reduction。**没有声称某一篇旧论文
已经原样实现全部 OCAR 原生接口和全部物理成本。** 单篇不含所有术语不能维持
概念新颖性；通用可表达也不能替代对某个具体新算法的优先权与性能审查。

关键一手入口：

- [de Kleer 1986, ATMS](https://dekleer.org/Publications/An%20Assumption-Based%20TMS.pdf)：
  §§4.2、4.7、4.9 的多支持与更新/撤销。
- [Deshpande–Hellerstein–Kletenik, SBFE](https://arxiv.org/pdf/1303.0726)：
  certificate 语义与付费 adaptive testing。此处未使用有争议的旧 adaptive-cover
  近似界；详见分线审查的后续修正范围。
- [Morgenstern–Garg–Pfenning 2011, LPCFS](https://people.mpi-sws.org/~dg/papers/stm11-lpcfs.pdf)：
  §4 的 proof/procap/dependencies、撤销检查、原子消费与崩溃窗口。
- [Hill–Komendantskaya–Petrick 2020, Proof-Carrying Plans](https://arxiv.org/pdf/2008.04165)：
  §3.1–3.2 的部分状态、相容世界和有条件 soundness。
- [Bonet–Geffner 2000](https://cdn.aaai.org/AIPS/2000/AIPS00-006.pdf)：
  belief 内共同 applicability 与 minimax/expected cost。

## 2. 原优化式还不是一个闭合算法问题

### 信息、证明与原生资源分开

令公开 contract 为 T，当前合法信息为 I；兼容集合为 `Compat_T(I)`，且必须
非空。证书引用合法、有效的证据与 sound 推理规则，不因“有 Γ”额外排除世界。
动作 enabledness、binding、authorization 与全部允许后继的 effect obligation
分别声明；没后继或矛盾信息不能借全称量化获得真空保证。

三种缺口必须区分：

1. 世界可能未变，但现存观察不够：合法 query 可补知识。
2. native guard 已假、资格已消耗或撤销：read 只能证实状态，恢复需额外合法
   世界动作/新授权，有时根本不可恢复。
3. 证明语言/契约模型不够：未找到证书不等于没有证书，更不等于信息不可能。

### 最小 Q 与最小 policy 不同

`Γ_surviving ∪ Ans(Q) ⊨ Ψ_a` 使用的答案在查询前未知。若 Q 根据真实答案选，
它是 offline witness；若一个固定 batch 对全部答案都充分，可能必须查询更多；
若可根据回执换 branch，则应优化合法 observation policy π。查询还能改变随后
的权限、资源和世界，须使用完整原生转移，不默认全部 reads 纯观察。

需要固定 expected、worst-case、competitive 或已知 trace 的准则；没有合法
先验就不自造 expected cost。retain bytes、proof/index、维护计算、补取、模型
与编译/优化的代价分项报告，再指定目标权重或 Pareto 关系。

### 安全还需要任务完成约束

仅有“每个 committed action 携带有效证书”时，永不提交即零成本可行解。
优化必须加入原任务完成/覆盖约束及其 horizon；不能靠 abstain 赢成本。
若某相容世界确实不满足 Ψ，只做查询不可能强迫 Ψ 变真。布尔分类参考必须有
经过证明的负终点，真实任务则按原生政策和评分决定后续恢复或失败的含义。

## 3. 已执行的强经典控制见证

新写并实跑 `experiments/oacr_support_kill/active_acquisition_classical_witness.py`，
输入仅为公开自构四位公式，没有任何 benchmark 或私有任务数据：

\[
 \Psi=(x_1\land x_2)\lor(x_3\land x_4),\qquad
 p_i=1/2,\quad c_i=1.
\]

穷举 16 worlds、81 partial observations、24 fixed orders、16 batch subsets。
用 truth-table 全称语义与独立 DNF 停止规则交叉检查；费用用 `Fraction`。
root 独立重跑，全部 JSON 结果与子代理保存结果一致。

| 比较对象 | 精确查询费用 | 含义 |
| --- | ---: | --- |
| Offline 最小 0/1 证书 | 每个 world 都为 2 | 已知答案后选证据；不是合法在线策略 |
| 最优固定顺序，遇充分证书即停 | 期望 25/8 | 已允许早停，仍不按结果换顺序 |
| 经典 exact adaptive decision tree | 期望 21/8 | 保留未失效证据，按结果补 hole，取得 0/1 证书即停 |
| 最优 minimax / 全答案 determining batch | 各 4 | 两种不同优化问题在此例恰同数值 |

这说明“较固定查询/全刷新更省”可由成熟 adaptive testing 获得，不是 OCAR
结果，也不是官方任务成绩。未据此宣称所有复杂状态依赖查询已有高效最优解。
复核命令：

```bash
python experiments/oacr_support_kill/active_acquisition_classical_witness.py \
  --out /tmp/support_kill_classical_verification.json
```

## 4. 真实载体：成立机制与未成立叙事

- **BFCL**：公开源码的 `sort` 不写文件、排序序列化行；`tail` 依赖原序。
  排序回执通常丢失原序，且存在空行序列化边界，不能无条件当作精确多重集。
  此为观察粒度差，不是自然 freshness 失效。官方接收规则下旧完整实验
  仍各省调用 0；本轮未新增任务收益。
- **τ² retail**：items 修改消费 strict pending 资格；重读不会恢复。政策要求的
  用户确认不是 native confirmation token/ledger。此前 ready/spent/epochs 属于
  合成适配审计，不能当作原生发现。
- **τ² telecom**：用户付款/设备工具会改变 assistant 不能直接看到的状态。
  半双工调度限定变化区间；assistant 连续工具 read→write 之间不能任意插入
  用户工具。合法重新核实 carrier bill 或引导用户做设备检查已有原生流程。
- **AppWorld**：公开源码确有替代 guards、付款请求消费、draft 删除与跨应用
  effect。但未查得该 pin 的独立自然后台写者；`updated_at` 在冻结时间下不能
  充当每次写都递增的 version。不存在通用公开 exact dependency/readset/CAS
  metadata 接口；少量 API 的人工审计不等于自动完整编译。

这些是代码/政策层的机制核查，不是 fixed official tasks 已出现所有机制的实证。
不添加外写者、不改 task、actor 权限或评分来制造候选优势。

## 5. 退出后的执行边界

当前候选按抽象概念退出核心。未建 OCAR Support-Lifecycle producer、未运行新
官方比较、未获得全局优先权清除或独有算法优势，512-unit bank 不读不解封。
完整 ACE 学习角色尚未执行；上一轮子代理 train 3/3 是同一场景的可行性结果，
不能升级为本轮方法成绩。

若以后重新进入，只能带一条具体的 native fragment、可靠信息/事件语义和新
算法命题：更广结构、可计算构造、同保证下的复杂度/成本界，以及相同任务、
actor、合法信息和完成约束的实际比较。对手必须是冻结且可实现的控制，保留
alternative proofs、局部维护、adaptive sensing 和共享代价；不能把整个经典
文献集合当一个免费 oracle，也不能只打全刷新。通用 reference 的指数成本是
寻找结构算法的理由，尚不是当前算法已有独立增量的证据。
