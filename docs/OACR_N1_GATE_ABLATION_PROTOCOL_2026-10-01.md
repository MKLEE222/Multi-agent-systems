# N1 all-key gate ablation

Frozen before ablation outcomes, after the observer replay established zero
native gate activation for B0/B1/B2 on all 66 registered future queries.
Authority: retrospective diagnosis on the same eight exposed development units.

The unchanged original runner is replayed at its recorded settings. After each
native variant evaluation, perform one extra evaluation with every stored radius
set temporarily to 1,000,000. Use the same stored keys and values, queries, labels
and generation settings. Restore original radii and CPU/Python RNG state before
the next native operation. No training, label-selected radius, unit exclusion or
key/value change is permitted. The original report must match its reference
summary and all unit records exactly, or the ablation is uninterpretable.

Record actual gate activation, layer-output change, answer change, per-query
gain/loss and macro/pooled correctness. Verify that all values remain copies of
the base edit value. Compare forced B0/B1/B2/A0 predictions without selecting
the best variant. Under identical copied values and identical replacement masks,
opening every gate should remove any dependence on nearest-key identity. A
violation is an implementation discrepancy to investigate.

This deliberately broad intervention diagnoses whether opening the inherited
value pathway changes answers and whether that copied value is useful here. It
does not justify this radius for deployment, supply an oracle ceiling, establish
family impossibility or measure operational quotient repair. Its extra native
calls and outcome-visible status are charged to diagnosis. These eight units
cannot acquire new confirmatory status. The 512 evaluation units remain sealed.
