# OACR 期刊路线验收记录 — 2026-09-30

## 验收范围与结论

本记录验收 [期刊与专刊深挖](OACR_JOURNAL_SPECIAL_ISSUE_DEEP_DIVE_2026-09-30.md) 中的投稿路线、费用、征稿期限和 JLAMP 指标。它不重新验收 OACR 的实验与论文论证。

**结论：期刊路线可用；两个 JLAMP 专刊的外部原创稿资格待编辑确认。** 零作者 APC 的可行路线已经有出版方依据：JLAMP 选择订阅出版，或投稿 LMCS。按目前的论文叙事，先保持 JLAMP 常规稿兼容；专刊资格确认后再决定是否切换入口。期刊适配度是基于论文内容作出的编辑判断，尚未获得期刊编辑确认。

## 投稿决策

1. **现在：**把论文按 JLAMP 常规稿的形式推进，突出 formal adequacy、contract-relative quotient、representation repair 和 native validation 的连贯论证。
2. **并行确认：**向两个专刊客座编辑询问外部原创稿是否可投，以及 OACR 的具体主题是否在范围内。当前没有发送询问信；本记录不把编辑回复写成既成事实。
3. **确认后：**若 Components Operationally 接收外部原创稿且主题契合，优先评估该专刊；若不合适，沿 JLAMP 常规稿路线；若形式化部分达到 LMCS 的投稿要求，LMCS 仍是开放获取且零作者费用的备选。
4. **正式填报影响因子/分区时：**使用单位认可的 JCR 年度与学科口径，保存当年的 Clarivate 单刊页面或图书馆认证记录。当前可确认的公开数据按上表表述。

## 尚未通过的门槛

- 两个专刊对非关联会议作者的原创稿开放资格；
- JLAMP 在最新可用 JCR 年度的单刊分区，以及出版方当前展示的 1.0 对应哪个指标年度；
- 论文终稿是否满足目标期刊的实际审稿期待；
- 作者所在机构或基金的开放获取要求。

这些门槛会影响最终投稿入口或行政填报，但不妨碍继续准备 JLAMP 常规稿。
