## 1. 论文的中心对象

方法相对强基线的增益回答“怎样做更好”。论文还要回答“系统中发生了什么、为什么发生、何时发生、何时不会发生”。现象必须在不采用我们新方法的情况下能够定义和观测；机制预测也必须在相应确认结果暴露前固定。

OACR 直接承接 BRFP 线。SQEC/EEQ 是同源参照，它们已经包含行动改变证据资格及合法纠正路径的现象与限定比较，但不直接定义 OACR 的新增问题。这里的待完成义务针对 OACR 自身的预算化维护或跨载体规律，不宣称同源原版缺乏现象，也不把新缓存候选的否定结果当作原版方法失效。谱系与证据分界见 [研究地图](OACR_LIMITATIONS_LED_RESEARCH_MAP_2026-10-01.md#研究谱系与-oacr-的新增义务)。

本轮候选现象是：

**在当前行为和资源近似匹配的表示中，一个组件的信息对后续执行的作用，随原生操作及其他组件提供的支持而变化。某些当前可省略的组件，在操作破坏替代支持后变得必要；增加或恢复有效支持则可能使其再次可省略。**

这里的“必要”首先是对指定操作、观察和组件族的条件性判断。它不是跨一切未来任务的固有信息价值，也不意味着从真正遗失的信息中凭空恢复内容。

这是从底层组件与算子提出的机制假设。一般性的行为等价、信息必要性及依赖失效早有基础理论；能否形成新贡献，需要具体的、稳定的实证规律或新的结构解释。一个设计出来的反例、一个新名字、一个提升后的分数都不足以完成这件事。

## 3. 独立于新方法的测量

沿用 [底层规格](OACR_OPERATOR_FIRST_FOUNDATION_2026-10-01.md) 的可执行表示族。只有载体确有可执行保留/解码接口时，使用 P_S(x)=D_S(E_S(x))。记原生操作 a 下的误差为

\[
 L_a(S;x)
 =d\!\left(q(T_aP_S(x)),q(T_ax)\right).
\]

a 为空操作时得到当前观察误差 L_0。非法执行、权限错误与 soft 任务误差分别保留，不能合成一个掩盖违法输出的分数。不能执行的接口标为不可测，不能按零误差处理。

组件 i 在保留集合 S 中、针对操作 a 的移除效应定义为

\[
 V_i(a,S;x)=L_a(S\setminus\{i\};x)-L_a(S;x).
\]

这既可以为正，也可能为零或负；它是固定原生实现的条件干预效应，不是一般信息论意义上的内在价值。若基准 S 本身有误差，仍报告该误差，不把 V_i=0 解释为绝对安全。

两个组件的交互可用

\[
 \Gamma_{ij}(a,S;x)
 =L_a(S\setminus\{i,j\};x)
 -L_a(S\setminus\{i\};x)
 -L_a(S\setminus\{j\};x)
 +L_a(S;x).
\]

衡量。这个有限差分对比是普通的交互测量，不是新定理。Gamma 不为零表明在这一误差尺度上移除效应不相加；它不能单独识别“替代路径”或语义因果机制。

需要检验的规律：

1. **操作选择性：** 当前移除效应小，但某类预先声明的操作下效应大；对无关操作效应仍小。
2. **条件性：** 同一个组件的效应会随有效支持的存在、失效与恢复按结构预测改变。
3. **可预测边界：** 在因果不受影响区、支持仍完整或已消费完相关动作预算的条件下，效应应消失或受界限制。

容忍度、效应量、操作分组、误差尺度与统计单位在独立确认前确定。V 和 Gamma 的数值不跨不同载体的损失尺度直接比较。

## 4. 机制干预，而非成功案例收集

每个来源任务保留同一原生解释器与完整参考。固定共同操作面板，报告全任务分母及无法执行的情况；不能先找到能分离的操作再把它当代表性发生率。

一个最小机制实验包含以下因素：

| 因素 | 条件 | 所解决的不确定性 |
|---|---|---|
| 目标组件 | 保留 / 省略 | 目标组件是否实际影响执行 |
| 支持组件 | 有效 / 经指定操作失效 / 经合法程序恢复 | 效应是否跟随所声称的支持结构 |
| 原生操作 | 预计受影响 / 预计不受影响 | 是否为操作选择性，而非所有执行整体损坏 |
| sham 干预 | 类型、数量及资源相近的无关组件处理 | 是否仅由更长输入、内存压力或一般执行扰动解释 |

恢复干预必须实际合法且可执行；不要求每种权限撤销可逆。缓存中的共同误差抵消也不能直接等同于记忆中的替代来源，它们是否属于同一机制需要额外证据。

观察顺序是：固定表示和机制预测 → 执行原生干预 → 审计实际保留内容与轨迹 → 最后测试修复方法。完整重建、成熟版本/依赖维护和其他强方法也要进入现象测试，以判断它们保留了什么结构、在哪些条件消除了现象。

匹配当前质量与资源的跨表示对比是描述性对比。把当前正确的样本筛出来之后，不据此估计未经说明的总体因果效应。主要因果证据来自同一来源任务中的固定因素干预。

## 5. 如何避免与已有“无复活”结论冲突

对下一次指定操作的需求可以改变；对一个包含全部允许未来历史的充分表示，则不能在原契约内凭空出现先前完全不需要的区分。

已证明的 budget-consumption 边界是：在原始图契约中安全省略的组件，不会在合法消费剩余预算时重新成为必要。若新候选实验声称违反它，先检查是否扩大动作族、重置时域、改变观察、删除其他原先永久支持，或发生执行误差。

所以要分别标记当前读取、单次操作和整个剩余契约的需求。不能把三个判据混用来构造“惊人现象”。

## 6. 现有证据能支持到哪里

| 证据 | 当前支持 | 不支持 |
|---|---|---|
| One-delta budget audit | 在限定 DAG 类中由 cut 决定需求，合法预算消费的可维护性 | 新自然现象、通用信息增长定律 |
| Multi-addition audit | 限定图类中的组件条件性；独立 gate 会过保留 | LLM 中普遍存在同一机制；新的通用交互理论 |
| R3 action-panel development | 相同动作数量的面板具有不同区分能力 | 无选择偏差的总体发生率，跨载体效应量 |
| GRACE N1 | 原生 B0/B1/B2 在 66 个开发未来查询中预测一致；强制门控有部分值作用 | 新主现象、辅助 key 几何优势、真实可维护充分表示 |
| 缓存原生机制检查 | 96 个小模型配置及一个预训练模型的 12 个手工探针，支持缓存覆盖编辑位点会切断后缀响应；精确因果边界恢复响应 | 完整编辑管线复现、自然任务发生率、全成本优势、机制首创性、共享记忆/码本具有同一机制 |
| 共享记忆、码本候选 | 问题及接口已声明 | 原生运行证据、自然任务确认、机制首创性 |

OACR 新增的预算化维护或跨载体规律，尚未建立足以支撑其主贡献的独立自然现象证据。这是该增量的研究义务，不反向否定 SQEC/EEQ 已有的现象与限定比较；也不能仅用原版方法比较替代新增主张的验证。

## 7. 缓存候选的具体入口

官方模型源文件完整性和组件运行依赖已解决，[缓存预检](OACR_CACHE_ZO_CANDIDATE_PREFLIGHT_2026-10-01.md)的固定输入、单 token 子集已执行。预测、完整分母、数值对照及判决见 [缓存响应机制探索](OACR_CACHE_RESPONSE_MECHANISM_EXPLORATION_2026-10-01.md)。固定因果不受影响前缀是现象消失的对照；其简单修正已消除本轮结构性差异。

新增静态检查入口来自已校验的 rome/zo.py：calculate_jvp 顺序执行 center、minus、plus 的损失调用；zero_order_loss 同时涉及可初始化的 target/KL 状态及缓存刷新分支。这要求分别记录调用前后的缓存与辅助状态，再比较冻结同一锚点的配对评估、完整原生顺序及反向配对顺序。顺序差异需在同样方向和扰动尺度下测量。

固定同一缓存锚点的 288 个小模型执行变体没有配对顺序差异；完整训练器的 target/KL 初始化、刷新与连续优化尚未检查，不能宣称已排除所有顺序效应。若只是遗漏 mask、版本或批次身份，归为实现修复。如果只有原生执行 bug 而无更一般的机制，也不升级为强论文主现象。

缓存 loss 的共同误差与反对称误差对有限差分影响不同，是已有代数与数值分析事实。需要发现的是实际原生过程里哪些组件和更新引起系统性的误差结构、怎样预测其出现边界；不是再证明一次误差除以扰动尺度的恒等式。

## 8. 贡献结构与推进门槛

论文可以围绕以下相互支撑的对象组织：

1. **现象：** 一个不依赖我们新方法、在独立任务中可重复观察的具体规律，附发生条件和反例。
2. **机制与形式结果：** 由组件和算子解释规律，并预测尚未观察的干预结果与消失边界；明确继承的基础数学。
3. **方法：** 把机制转成可计算的需求证书与维护程序，验证它改变了所预测的失败路径，再测同输入同资源下的实际收益。

按用户最新目标，尽量让现象、理论、方法每层各有独立首创内容，逐层核对具体先行结果；目前未宣称已经达到。若已有解释完整覆盖现象与边界，就重新选该层候选；若机制干预失败，就修改或放弃假设。已成立现象与限制仍保留，但被成熟强对照完整追平且没有剩余独立保证的算法不继续升格为主贡献。新算子须在共同原生任务上证明可独立检验的增量；跨系统须复用同一核心预测/构造规则，不能把各载体分别做过审计当作统一升级证据。

本次已新增组件机制实验和预训练手工探针；尚未测量支持替代、失效与恢复的完整交互，也未检验跨载体规律。学习型刷新主张在此固定输入场景暂停。旧 512 单位评估仍封存，T2/T5 仍开放。
