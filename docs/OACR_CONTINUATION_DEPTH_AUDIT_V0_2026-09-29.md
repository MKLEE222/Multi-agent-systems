# OACR Continuation-Depth Audit v0

**Date:** 2026-09-29  
**Status:** evidence reclassification after qualified-continuation bridge  
**Rule:** protocols are not counted as positive evidence; only accepted/executed outcomes are assigned empirical status.

## 1. Audit target

The immediate COMPOSE question is whether any already executed carrier contains a pair with:

\[
X \equiv_1 Y
\quad\text{but}\quad
X \not\equiv_2 Y.
\]

A stronger target is restoration without continuation restoration.

This audit classifies existing assets before any new COMPOSE-v1 outcome is authorized.

## 2. Evidence classes

- **D0:** same registered present/READ only.
- **D1+:** present-equivalent states separate under at least one registered one-step action.
- **D1=:** present-equivalent states remain equivalent under the complete registered one-step action panel.
- **D2+:** D1-equivalent states later separate under a registered two-step continuation.
- **D2=:** D1-equivalent states remain equivalent through the complete registered H=2 continuation.
- **REST candidate:** present restoration is constructed or observed, but later continuation preservation has not yet been tested.
- **REST+:** present and immediate continuation restored, later continuation differs.

## 3. Current OACR assets

### R3 / R4 relational deletion

Empirical status: **D1+ plus exact depth-1 representation closure**.

- R3: 272 states, shared 64-action deletion panel, 101 operational classes.
- R4 building: 272 states, shared 64-action panel, 23 operational classes.
- In both, current closure is too coarse and full asserted identity too fine.
- D1/D2-R and R4 contract-gated redesign exactly match the registered one-step operational quotient and replay every registered state-action cell with zero mismatch.

What this does **not** establish:

- no registered two-step continuation contract was used for the accepted redesign;
- therefore these assets do not yet establish D2+ or D2=;
- exact D1 closure must not be described as compositional closure.

Scientific role under the new architecture:

> exact first-order generator and representation-closure baseline.

### WACT-R

Empirical status: **prospective D1 activation / selectivity within the relational carrier**.

The strict artifact reverify completed successfully for the existing frozen INCLUDED roots. WACT-R prospectively demonstrates that individual deletion actions can leave a latent redundant-edge distinction inert or make it consequential under a one-step native replay.

What it does **not** establish:

- the action panel is still depth-1;
- it does not show that one action changes the semantic status of a later action;
- it therefore remains WRITE evidence, not COMPOSE evidence.

### G5 natural Git same-contract

Empirical status: **natural D1+ and D1= mixture under one frozen 12-target panel**.

Held-out validation contains:

- 2/48 same-tree pairs requiring one-step separation;
- 46/48 same-tree pairs remaining equivalent under the registered one-step panel;
- target-ancestry vector exactly matching that finite D1 partition.

High-value COMPOSE implication:

- the 46 D1-equivalent pairs are a natural pre-existing candidate bank for a depth-2 audit;
- no accepted result currently shows that any of those 46 later diverge after a shared first operation.

This is therefore the strongest current natural bank for asking D1= -> D2+ without constructing new current-state collisions.

### G1/G2 Git history

Empirical role: **D1 positive control / natural-history positive control**.

The registered object is same complete tracked content with different history, followed by one native merge.

Construction B is especially relevant to restoration because one branch restores file content after inheriting target history, yielding the same current tree as the comparison branch while retaining different ancestry.

Current boundary:

- this is a strong **REST candidate architecture**;
- it is not yet REST+ because the accepted question was one-step merge divergence, not "immediate continuation restored but later continuation differs";
- do not relabel the existing outcome as a prospective restoration-hysteresis result.

### GRACE L1b

Empirical status: **D2= negative boundary**.

Accepted prospective bank:

- 64 states;
- 224 H0 collision pairs;
- 4 frozen H1 actions;
- complete 16 ordered H2 action pairs.

Result:

\[
H0 \to H1 \text{ separations}=0,
\]

\[
H1 \to H2 \text{ separations}=0.
\]

Thus every registered collision pair remained equivalent through the complete registered H=2 contract.

This is important under the new architecture:

> hidden persistent-state distinctions do not automatically become relevant merely because operations are composed.

GRACE L1b is therefore a direct negative control against a trivial "longer horizon always exposes hidden state" story.

### Parameter fine-tuning fold0 / L2b

Empirical status: **learned D1+ positive**.

The independently replayed fold0 pair is H0-equivalent and separates under each of the registered H1 actions 51/29/73.

Current boundary:

- because separation already occurs at H1, this witness cannot establish delayed D2 activation;
- it remains a learned first-order positive control.

## 4. SQEC bridge assets

SQEC is not imported wholesale into OACR. The relevant executed results are treated as mechanism evidence for dynamic continuation coordinates.

### Stochastic multistep legality / policy-tree audit

Executed controlled result:

- full policy observes before commitment under a legality precondition;
- deleting legality preconditions preserves the projected value at the coarse level;
- full replay then encounters an illegal observation, cost 10, regret 46/5;
- an independent enumerator over 34 finite contingent policy trees matches the typed dynamic policy.

OACR interpretation:

> a coarse state/projection can preserve current projected value while failing to preserve legal future continuation.

Current classification:

- **strong dynamic-qualification under-refinement witness**;
- **not yet a clean OACR D1= -> D2+ witness**, because the existing SQEC experiment was not registered around OACR's continuation-equivalence ladder and the exact "same complete immediate interface" condition has not yet been reconstructed.

Action:

- reconstruct the compared SQEC states/policies under the new \(\Gamma\) coordinates before deciding whether the existing result already satisfies D1= -> D2+.

### Shared-root transition / dynamic-region audit

Executed controlled result:

\[
P(o,q' \mid q,\alpha)
\]

contains action-conditioned qualification-root transitions. Marginally indistinguishable root summaries can induce different joint qualification risk and different selected policies.

OACR interpretation:

> future qualification dynamics can depend on latent joint structure omitted by a coarse state summary.

Current classification:

- mechanism support for endogenous continuation;
- not yet accepted as D1= -> D2+ until the immediate continuation interfaces are explicitly matched.

## 5. Claim-Relative Representation bridge assets

### Recovery-depth protocol

Status: **not evidence**.

The protocol was superseded before run because scalar recovery depth was judged too narrow and replaced by task-relative recovery contracts and recoverability profiles.

Scientific-use status:

- conceptual support only;
- cannot enter an empirical claim ledger.

### Argument reinstatement / access-transfer work

These executed studies show representation/workflow-relative access and formal argument-state changes, but no inspected accepted result yet satisfies the strict restoration-hysteresis condition:

\[
\text{present restored}
+
\text{immediate continuation restored}
\not\Rightarrow
\text{later continuation restored}.
\]

They remain bridge candidates rather than COMPOSE evidence.

## 6. Current empirical verdict

### Already established

1. **D1+ exists across exact relational, natural Git, and learned parameter state.**
2. **D1= exists naturally in Git under a finite panel.**
3. **D2= exists prospectively in GRACE L1b.**
4. **Dynamic qualification / legality can be action-conditioned in SQEC and can matter for downstream policy/replay.**
5. **Depth-1 representation closure and constructive redesign are already demonstrated in relational carriers.**

### Not yet established

The project currently has **no accepted clean witness** of:

\[
\boxed{
D1= \rightarrow D2+
}
\]

under the new qualified-continuation definition.

It also has no accepted clean:

\[
\boxed{
REST+
}
\]

witness.

These are therefore legitimate scientific gaps rather than rephrasings of existing results.

## 7. Next execution gate

Before designing a new carrier:

1. reconstruct SQEC multistep legality and shared-root examples in the \(\Gamma\) interface and test whether the compared states truly match at depth 1;
2. use the 46 held-out G5 D1-equivalent natural pairs as the first Git depth-2 candidate bank;
3. inspect G1 Construction B as a restoration seed, but register a new later-continuation test before any new outcome;
4. do not retune GRACE L1b; retain it as the D2 negative control;
5. do not use the fold0 D1 positive as evidence for delayed activation.

If steps 1-3 yield no pre-existing accepted D2+ witness, freeze COMPOSE-v1 prospectively.
